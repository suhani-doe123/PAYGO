💳 PAYGO – Buy Now, Pay Later

PAYGO is a modern Buy Now, Pay Later (BNPL) application designed to make shopping and installment payments simple, flexible, and convenient.

✨ Features

- 👤 User Registration & Login
- 🛍️ Product Browsing & Ordering
- 💳 BNPL / Installment Payment System
- 📦 Order Tracking
- 🧾 Payment Management
- 👤 User Profile
- 📱 Mobile-Friendly Responsive Design
- 🔐 Firebase Integration
- ⚡ PWA Support

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Firebase
- Progressive Web App (PWA)

🎯 Purpose

A modern BNPL app designed to make shopping and installment payments simple, flexible, and convenient.
